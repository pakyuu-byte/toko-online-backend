# Toko Online Backend - Final Project

Backend e-commerce dengan Node.js, Prisma, Midtrans & Cloudinary.
Server running on http://localhost:3000 ✅

## Fitur Selesai
- [x] Auth JWT
- [x] Product CRUD
- [x] Cart
- [x] Order / Checkout
- [x] Payment Midtrans Snap - Modul 7
- [x] Upload Cloudinary - Modul 8

## Cara Jalan
npm install
npx prisma generate
npm run dev

## Endpoint Penting
POST /api/auth/register
POST /api/auth/login
GET /api/products
POST /api/products/upload
POST /api/payment/create-payment
